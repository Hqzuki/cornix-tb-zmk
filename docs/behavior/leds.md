# LEDの挙動

Cornix側のLEDは、接続先プロファイルやレイヤーを表示します。BLUETOOTHレイヤーでは内側LED表示をバッテリー残量に切り替えます。表示処理は`drivers/status/`にあります。

## レイヤー色

| レイヤー | 色 |
| --- | --- |
| MAC (0) | 青のブリージング |
| WIN (1) | 赤のブリージング |
| NUMFN (2) | 緑 |
| BLUETOOTH (3) | 白 |
| PAN (4) | 黄 |
| GESTURE (5) | マゼンタ |
| MOUSE (6) | 消灯色 |

レイヤー色はCornixの外側LEDに表示します。右手（Central）が左手とXIAOへレイヤー／プロファイル状態を同期し、レイヤー変更時は即時再描画します。

## Bluetooth表示

- Cornix右手（Central）の外側LEDは選択中のホストスロットを表示します。0＝青、1＝赤、2＝緑、3＝黄、4＝紫です。これはスロット選択を示し、接続成功そのものを示す色ではありません。
- 左手の外側LEDは現在のレイヤーを表示します。
- BLUETOOTHレイヤーでは、各Cornixの内側LEDがその側で取得したバッテリー残量を表示します。51〜100%＝緑、21〜50%＝黄、0〜20%＝赤です。未取得状態は消灯します。

## 電源・アイドル時

- 右手の内側LEDは、Peripheral（左手・XIAO）が接続中または未接続の間、青の点滅／点灯も表示します。
- XIAO内蔵RGB LED（Peripheral）は、USB給電中の充電表示に使います。充電中は緑系ブリージング、残量95%以上で緑点灯です。PWMでCornixと同じ13/255（約5%）を上限にします。USB給電を外したときは通常、XIAO側のLEDを消灯します。
- アイドル用の別LEDパターンはありません。LED更新ループは動作中30 Hzで、Deep Sleepに入ると止まります。
- Cornix側のLED最大値はRGB各チャンネル13/255相当です。ベースMAC／WINのブリージングもこの明るさを上限にしています。
